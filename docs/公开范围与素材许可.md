# 公开范围与素材许可

这是整个制作项目的可接续源码仓库，不是原工作盘的逐字节镜像。

| 内容 | 处理方式 |
|---|---|
| 当前前四集的双画幅动画、字幕、时间轴、布局、事实来源 | 纳入episodes；登记来源和迁移改动 |
| 规范、任务单、核查/复盘模板、第五六集设计 | 纳入根目录与planning |
| 有价值的修订/独立复查/交接文字记录 | 纳入history及单集目录，标为历史证据 |
| 原创木块音效 | 无损gzip纳入assets，prepare恢复 |
| OFL字体 | 纳入许可与固定版本下载/校验清单，安装在本地 |
| 授权不明的BGM、含它的混音和视频 | 不公开；自备授权混音另行导入 |
| 重复MP4、ZIP、抽帧、渲染缓存、虚拟环境、浏览器 | 不入Git，可从工程重新生成或另做备份 |
| 被上游许可排除的参考片/图片/镜头说明 | 不分发，只保留上游入口与许可说明 |
| 旧130秒废弃工程、各次重复压缩包、全部历史截图 | 仍在原本地档案，不以旧版覆盖当前工程 |
| 登录凭据、密钥、个人邮箱、机器运行日志 | 不纳入公开仓库 |

`provenance.json`保留复制前摘要，公开文件可能因路径脱敏、入口适配而变动；它不能拿来验证迁移后源码字节。当前导出报告记录真正使用的源码/字体/音轨摘要。初始迁移检查不改写完整视听、平台或用户验收状态。

需要恢复原版含BGM成片时，除了本仓库，还需要你自行保管且有权使用的音源/混音。GitHub源码仓库不能替代这部分私人备份；不能声称仅克隆仓库就能恢复原版BGM。
