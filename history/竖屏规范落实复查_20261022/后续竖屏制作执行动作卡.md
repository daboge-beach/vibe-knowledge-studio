# 后续竖屏制作执行动作卡

这是本会话把根目录v2.0规范落到制作动作的工作入口，不替代根规范。历史四集按已锁定基线复查；新片收到选题后才建任务，不自行创建内容。

| 关口 | 我实际要做的动作 | 留下的文件/放行条件 |
|---|---|---|
| 开工选版 | 读现行规范及最新交付清单，核对父版本、时长、fps、SRT、音轨和摘要，划定横屏边界 | 复制任务单；分别写内容、技术和用户验收状态 |
| 策划 | 写一个具体场景、核心问题、有证据的认识、可带走的方法；比较三个开场方向 | 每个方向写0—2秒发生什么、5秒能看懂什么；先事实后定稿 |
| 事实 | 每个数字、年份、因果、年龄/风险范围逐条接到原文位置；写实际取得的是正文、摘要还是历史核查 | 主张→来源ID→字幕/图表；保留对象与局限，无证据不硬说 |
| 分镜 | 同时设计字幕和动作；逐镜回答主体、动作、理解；把开始、接触和落定写出来 | 逐镜输出区间、阅读起止、景别/主体尺度、停留理由、来源ID及音乐节点 |
| 竖屏构图 | 新片1440×2560/60fps；主体优先，手/道具/结果需要时近景；顶部标题让位；文字放不下就重排 | 360×640单帧检查正文、关键标注和动作；不以无限缩字过关；平台UI需有实际证据 |
| 样片G3 | 先完成最难一镜，再做前约30秒；第一轮看主体/因果/接触/阅读，修改后第二轮同点复看 | 问题时间码→具体修改→新旧同点图；无问题写未发现，不能虚构改动；展示后继续已授权工作 |
| 全片 | 沿样片语言铺全片；前15秒逐秒、全部场景/转场、动作前中后、正文逐条阅读、长停留逐项判断 | >3秒低变化、读完空等约0.8秒、短长字幕只是候选，全部给保留/修改理由；装饰动不算信息 |
| 配乐 | 音乐独立编排；现四集连续原曲0—本集时长，不内部剪接、不变速/循环；画面配合已选节点，音效跟接触 | 固定字幕真实时钟，视觉映射各一次；音源/混音版本、增益、首尾淡化和节点表 |
| 最终MP4 | 完整解码、规格/帧数/音画长度、分段首中尾及全部节点对照；从最终MP4解码核查实际音轨 | 整段匹配、旧断点前后各3秒、全踩点、最后10秒；AAC填充与内容漂移分开记录 |
| 主观验收 | 正常速度完整看最终MP4、完整听实际导出音轨，各自记文件、设备、区间、听看发现 | 客观检测、完整观看、完整试听、用户验收四栏分开；无法做的填未做，交待验收候选 |
| 包装交接 | 发布包与工程包分开；带/无BGM、两平台封面文案、SRT、来源、源素材/混音、实际记录齐备 | 明确内容版本/时间轴/音乐节点/色板字体/逐项摘要；ZIP解压预览、代表重渲、封面重导；内容变更写表 |
| 发布复盘 | 用户实际发布且给出后台数据后，用复盘模板分平台、分内容版本记录 | 24小时/7天同窗口；作品归因字段及分母确认后才计算；不操作账号，不承诺流量 |

固定片尾：

关注不焦虑爸爸  
陪孩子长大，也陪自己成长

不动横屏会话的工程；共用内容变更写入明确版本的交接表。当前四集没有获授权的新增选题，保持现行锁定内容与混音。
